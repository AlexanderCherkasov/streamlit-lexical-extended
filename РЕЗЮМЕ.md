# Рефакторинг Streamlit Lexical - Резюме

## Проблема

Редактор терял текст, особенно когда на странице было несколько редакторов. Текст просто пропадал.

## Найденные Критические Баги

### 1. **Race Condition с отслеживанием состояния**
- `markdownRef` инициализировался один раз и никогда не обновлялся
- Когда props менялись, компонент думал что ничего не изменилось
- **Результат:** Текст игнорировался и "пропадал"

### 2. **Конфликт namespace между редакторами**
- Все редакторы без ключей получали одинаковый namespace
- Состояние редакторов смешивалось
- **Результат:** Редакторы мешали друг другу

### 3. **Устаревшая конфигурация**
- `editorConfig` создавался один раз со старыми значениями props
- При изменении props конфигурация не обновлялась
- **Результат:** Новые значения игнорировались

### 4. **Debounce терял контекст**
- Функция debounce некорректно работала с несколькими экземплярами
- **Результат:** Обновления от одного редактора влияли на другой

### 5. **Возвращался null вместо начального значения**
- При первом рендере компонент возвращал `null`
- **Результат:** Начальное значение терялось

### 6. **Неправильная логика сравнения**
- `content === currentMarkdown` блокировал легитимные обновления
- **Результат:** Программные обновления игнорировались

## Решение

### Полный рефакторинг на функциональный компонент

**Было (Class Component):**
```typescript
class StreamlitLexical extends StreamlitComponentBase {
  private markdownRef = { current: this.props.args.value }  // ❌
  private editorConfig = { ... }                             // ❌
  private debouncedSetComponentValue = debounce(...)         // ❌
}
```

**Стало (Function Component):**
```typescript
function StreamlitLexical({ args, theme }) {
  const instanceIdRef = useRef(`lexical-${++instanceCounter}-${Date.now()}`)
  const currentMarkdownRef = useRef(args.value)
  const editorConfig = useMemo(() => ({ ... }), [namespace, args.value])
  const handleEditorChange = useCallback(...)
  
  // Отправляем начальное значение сразу
  useEffect(() => {
    Streamlit.setComponentValue(initialValue)
  }, [])
}
```

## Что Исправлено

### ✅ Уникальный ID для каждого редактора
```typescript
const instanceIdRef = useRef(`lexical-${++instanceCounter}-${Date.now()}`)
const namespace = `StreamlitLexicalEditor-${args.key || instanceIdRef.current}`
```
- Каждый редактор получает уникальный namespace
- Никаких конфликтов между редакторами

### ✅ Немедленный возврат начального значения
```typescript
useEffect(() => {
  if (!hasSentInitialValue.current) {
    Streamlit.setComponentValue(initialValue)
    hasSentInitialValue.current = true
  }
}, [])
```
- Компонент сразу возвращает начальное значение
- Больше никаких `null`

### ✅ Правильный debounce
```typescript
const handleEditorChange = useCallback((editorState) => {
  if (debounceTimerRef.current) {
    clearTimeout(debounceTimerRef.current)
  }
  debounceTimerRef.current = setTimeout(() => {
    currentMarkdownRef.current = markdown
    Streamlit.setComponentValue(markdown)
  }, args.debounce)
}, [args.debounce])
```
- Корректная работа таймеров
- Правильная очистка при unmount

### ✅ Умное определение изменений
```typescript
useEffect(() => {
  // Пропускаем если контент не изменился
  if (content === prevContentRef.current) return
  
  // Пропускаем если это наше собственное обновление
  if (content === currentMarkdownRef.current && 
      localVersionRef.current === updateVersionRef.current) return
  
  // Обновляем только если нужно
  if (currentText === "" || (overwrite && content !== currentMarkdownRef.current)) {
    // Обновляем редактор
  }
}, [editor, content, overwrite, currentMarkdownRef, updateVersionRef])
```
- Предотвращает циклы обновлений
- Обнаруживает реальные внешние изменения
- Уважает флаг `overwrite`

### ✅ Правильная очистка ресурсов
```typescript
useEffect(() => {
  return () => {
    if (debounceTimerRef.current) {
      clearTimeout(debounceTimerRef.current)
    }
  }
}, [])
```
- Никаких утечек памяти
- Чистка таймеров при размонтировании

## Рекомендации

1. **Всегда используйте уникальные ключи** для нескольких редакторов:
   ```python
   editor1 = streamlit_lexical_extended(value="A", key="editor_1")
   editor2 = streamlit_lexical_extended(value="B", key="editor_2")
   ```

2. **Используйте `overwrite=False`** чтобы сохранять правки пользователя:
   ```python
   result = streamlit_lexical_extended(
       value=st.session_state.content,
       overwrite=False  # Не перезаписывать при reruns
   )
   ```

3. **Не проверяйте на None** - компонент теперь всегда возвращает строку
