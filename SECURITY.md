# Security Policy

Please do not open a public issue for a suspected vulnerability.

Report it privately through
[GitHub Security Advisories](https://github.com/AlexanderCherkasov/streamlit-lexical-extended-/security/advisories/new)
with the affected version, impact, reproduction steps, and any suggested fix.
You should receive an initial response within seven days.

Only the latest released version is supported with security updates.
